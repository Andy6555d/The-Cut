# Immersive UX V4

- Display names: product rule is free-form player-chosen display names; duplicates are allowed and identity remains an internal unique ID. (Social/profile implementation belongs to Phase F.)
- CORE now says FIND THE CENTRE / TAP THE EXACT CENTRE OF THE SHAPE and uses a visible 3-second in-game jeopardy clock.
- MORE uses a visible 2-second in-game decision clock; no pre-game 3-2-1 countdown.
- TRACE failure/success copy is now semantic and cannot show MISSED alongside a threshold-cleared message. Threshold failures say NOT ACCURATE ENOUGH; valid clears say QUALIFIED.
- Existing COUNT 5-second and TRACE 10-second clocks remain.
